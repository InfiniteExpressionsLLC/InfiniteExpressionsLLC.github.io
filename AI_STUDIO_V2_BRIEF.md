# Infinite Expressions LLC — Website V2 / Google AI Studio Build Brief

## Objective
Rebuild the existing Infinite Expressions LLC website into a premium, cinematic, highly credible MedTech/AI R&D website while preserving factual accuracy, accessibility, SEO, and the company's current research-stage positioning.

The site must feel appropriate for:
- clinical and university collaborators
- MedTech and biomaterials researchers
- CAD / simulation / 3D scanning / additive-manufacturing companies
- AI and compute partners
- grant reviewers, accelerators, and startup programs
- prospective technology partners

Do NOT make the site feel like a consumer cosmetic brand, generic SaaS template, crypto site, or sci-fi game.

## Core brand direction
Visual tone:
- sophisticated medical technology
- precision engineering
- calm confidence
- premium but not flashy
- dark navy / gunmetal / cool silver / restrained blue
- high contrast and accessible
- subtle glass / depth only where appropriate
- clean typography and generous whitespace

Use the existing brand mark and existing verified copy as the factual source of truth.

## Hero
Create a strong first 5-second impression.

Headline direction:
"Reengineering the path to custom facial prosthetics."

Subhead:
Explain that Infinite Expressions is developing a human-supervised digital workflow connecting high-resolution 3D facial capture, IEAI-assisted engineering, professional CAD validation, and silicone additive-manufacturing research.

Hero visual:
- cinematic but technically credible
- abstract 3D facial mesh / point cloud
- scanning sweep / controlled data overlays
- no disturbing medical imagery
- no fake patient results
- no fake before/after imagery
- no claim of an already-completed clinical product

Primary CTA: Explore the Technology
Secondary CTA: Partner With Us

Immediately visible research-stage disclosure:
"Research-stage company — building technical feasibility, validation evidence, infrastructure, and partner relationships. Not currently offering clinical prosthetic services."

## Core interactive workflow
Build an interactive visual sequence:
3D CAPTURE → IEAI → CAD / ENGINEERING → VALIDATION → ADDITIVE MANUFACTURING

Each stage should open/expand on hover/click with concise explanation.

The interaction should be smooth and modern but preserve keyboard accessibility and reduced-motion support.

## IEAI section
Make IEAI feel like a real engineering platform rather than just a paragraph.

Full first reference:
"IEAI — Infinite Expressions Artificial Intelligence"

Positioning:
- local-first
- human-supervised
- assistive engineering system
- not an autonomous clinician
- audit / provenance controls
- structured validation
- 3D geometry components
- project knowledge
- data-governance boundaries

Visually show modules/cards such as:
- geometry analysis
- scan-quality review
- landmark / dimensional assistance
- fit-analysis research
- motion-analysis research
- manufacturing-readiness review
- provenance / audit trail
- local processing / privacy

Do not imply any capability is clinically validated unless the existing site explicitly says so.

## Verified progress vs planned capability
This distinction is extremely important.

Create a clear status system with categories such as:
- VERIFIED
- IN DEVELOPMENT
- PLANNED / RESEARCH DIRECTION

Never convert a future goal into a current accomplishment.

Current website copy is source-of-truth and must be retained unless a change improves clarity without altering meaning.

## SEO

- title and description quality
- Open Graph metadata

- indexability

- social preview

## Accessibility
Target WCAG 2.2 AA fundamentals:
- keyboard navigation
- visible focus states
- sufficient contrast
- semantic HTML
- meaningful labels
- reduced-motion handling
- no autoplay audio
- responsive at 320px+
- good tap targets
- skip link

## Performance
Avoid unnecessary heavy dependencies.
Animations should be CSS / SVG / lightweight JS where possible.
Optimize mobile performance.
Lazy-load noncritical assets.
Do not sacrifice speed for decorative effects.

## Final quality bar
A visitor from Siemens, PTC, NVIDIA, SOLIDWORKS/Dassault, a university research lab, an accelerator, or a MedTech funding program should understand within seconds:
1. What problem Infinite Expressions is addressing.
2. What technical workflow is being developed.
3. What IEAI is.
4. What has actually been accomplished vs what is planned.
5. Why the founder is uniquely connected to the problem.
6. How they could collaborate.

The result should feel like a credible early-stage MedTech engineering company with a distinctive mission, not a generic AI-generated website.
